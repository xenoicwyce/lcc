# Light Cone Cancellation for Variational Quantum Eigensolver Ansatz
The code in this repository implements the light cone cancellation (LCC) method used in *Light Cone Cancellation for Variational Quantum Eigensolver Ansatz*; arXiv: <https://arxiv.org/abs/2404.19497>.

The instances of dataset are generated by the Python package **NetworkX**. 

The $G(n,p)$ graphs are generated using `fast_gnp_random_graph()`, and the regular graphs are generated using `random_regular_graph()`.

The instances in the `dataset` folder are named according to their graph parameters. 
For example, `n100_reg3_seed0` represents a regular graph with 100 nodes, degree 3, and seed 0, while `n100_gnp01_seed0` denotes a $G(n, p)$ graph with 100 nodes, edge probability 0.1, and seed 0.

To see how to use LCC to solve Max-cut and other problems, see `lcc_vqe_tutorial.ipynb`.
